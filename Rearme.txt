1. Fase de Enumeración (Recolección de datos)Antes de atacar, necesitas saber dónde estás parado.cat /etc/passwd | grep -v nologin: Lo usas para identificar usuarios reales. Si ves un usuario llamado desarrollo o admin_web, ya tienes un objetivo para intentar ataques de fuerza bruta o buscar archivos mal protegidos en sus carpetas /home.getcap -r / 2>/dev/null: Es de los primeros comandos que ejecutas para buscar "vías rápidas" a root. Si un binario como python, perl o tar tiene la capacidad cap_setuid, puedes usarlo para generar una shell de root instantáneamente.2. Fase de Explotación de SudoSi lograste conseguir una contraseña (como "kali" en tu imagen) o si el usuario tiene permisos de sudo sin contraseña, el proceso es:Verificar permisos: Primero ejecutas sudo -l para ver qué comandos puedes ejecutar como root.Bypass de restricciones: Si no tienes una terminal interactiva (una "TTY" estable), el truco de echo 'password' | sudo -S [comando] es vital para ejecutar comandos administrativos a través de una reverse shell básica.Búsqueda de Binarios Peligrosos: Consultas sitios como GTFOBins. Si sudo -l te dice que puedes usar vim o find como sudo, usas esos programas para "escapar" a una shell de root.3. Consolidación (Obtener la Shell de Root)El objetivo final no es solo ejecutar comandos sueltos, sino tener una sesión completa:Usas echo 'password' | sudo -S su - o sudo -S /bin/bash para pasar de ser un usuario invitado a ser el dueño del sistema.Resumen del flujo de trabajo:Entras al sistema como usuario de bajos privilegios (ej. www-data).Enumeras usuarios y capacidades (getcap, /etc/passwd).Buscas contraseñas guardadas en archivos de configuración o historial.Escalas usando sudo -S una vez que tienes la credencial
